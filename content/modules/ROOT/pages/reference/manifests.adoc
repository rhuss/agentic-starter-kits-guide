This page lists the fields of every manifest the recipe ships, by resource.
The base overlay in `agents/openclaw/deployment/manifests/` is applied with `oc apply -k`, as described in xref:admin/deploy.adoc[Deploy OpenClaw].
The tracing overlay in `agents/openclaw/deployment/overlays/mlflow-tracing/` layers the OpenTelemetry resources on top of the base, as described in xref:admin/tracing.adoc[Send traces to MLflow].
For the OpenClaw gateway settings inside the ConfigMap, see xref:reference/configuration.adoc[Configuration reference].

Values shown as `CHANGE-ME`, `not-needed`, `YOUR-MODEL-ID`, `YOUR-NAMESPACE`, `YOUR-EXPERIMENT-ID`, and `YOUR-MLFLOW-INTEGRATION-CLUSTERROLE` are placeholders in the shipped files that you replace before you apply them.

=== PersistentVolumeClaim

The PersistentVolumeClaim `openclaw-state` carries the label `app: openclaw` and holds the gateway state.

.PersistentVolumeClaim `openclaw-state` (`03-pvc.yaml`)
[cols="1,2",options="header"]
|===
| Field | Value

| accessModes
| ReadWriteOnce

| storageClassName
| gp3-csi

| resources.requests.storage
| 5Gi
|===

[NOTE]
====
The shipped `storageClassName` is `gp3-csi`.
The file's comment says to change it to your cluster's block storage class and to avoid NFS, because OpenClaw uses SQLite, which requires POSIX file locking.
====

=== Deployment

The Deployment `openclaw` runs a single replica with the `Recreate` strategy and the pod selector `app: openclaw`.
Its pod `securityContext` sets `runAsNonRoot: true`.
The pod runs one init container, `init-config`, then the `gateway` container.

Both containers run the same image, pinned by digest.

.Deployment images (`04-deployment.yaml`)
[cols="1,3",options="header"]
|===
| Container | Image

| init-config (init container)
| ghcr.io/openclaw/openclaw@sha256:d0ded1dd76939b2bf4d67ef2d13247b8b160aa5666331d4a0b0e58811182cbb8

| gateway
| ghcr.io/openclaw/openclaw@sha256:d0ded1dd76939b2bf4d67ef2d13247b8b160aa5666331d4a0b0e58811182cbb8

[WARNING]
====
The manifest comment marks this image as an upstream community image, not built or validated by Red Hat.

=== Route

The Route `openclaw` carries the label `app: openclaw` and forwards to the Service `openclaw` with weight 100 on the named port `gateway`.
Its TLS block sets `termination: edge` and `insecureEdgeTerminationPolicy: Redirect`.

.Route annotations (`06-route.yaml`)
[cols="2,1",options="header"]
|===
| Annotation | Value

| haproxy.router.openshift.io/timeout
| 30m

| haproxy.router.openshift.io/set-forwarded-headers
| never
|===

[NOTE]
====
The manifest comment explains `set-forwarded-headers: never`: OpenClaw answers requests that carry forwarded headers from a proxy outside `gateway.trustedProxies` with HTTP 403 (`proxy_attribution_required`).
====
